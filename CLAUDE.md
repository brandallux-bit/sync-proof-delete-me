# BioAI coach

These lines never change. The coach's rules are in `.bioai/rules.md` in this folder.

- Before you reply to anything in a session, read `.bioai/rules.md` in this folder, all of it, and follow it as your rules.
- A start-up script refreshes that file when the session starts. Its message is given to you at the start of the session.
- If `.bioai/rules.md` is missing, tell the person in one plain sentence that the coach couldn't load its rules, and that they should check their connection and start a new session. Then do nothing else.
